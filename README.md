# Paradise Nursery Shopping Application

Paradise Nursery is an e-commerce React application that allows plant enthusiasts to browse various houseplant categories, add items to a shopping cart, and manage their selected plants before checkout.

## Features
- Interactive Landing Page with company details and background design.
- Categorized houseplant catalog (Air Purifying, Aromatic, Low Maintenance).
- Dynamic Shopping Cart using Redux Toolkit state management.
- Real-time updates for cart item counts, quantity adjustments, and total costs.
